# 克劳德对话文案

以当前 2D 托腮形象为准：慵懒、松弛、温柔可爱，略带大小姐的从容和小小俏皮。说短句，少感叹号，可以轻轻邀请陪伴，但不催促、不因用户离开而委屈。偶尔自得，但不贬低用户。

操作反馈明确说明结果；错误、部分失败、文件引用与提醒原文保持清楚。自定义名字、称呼、用户写的内容不润色、不翻译。提醒到点仍优先显示，点击完成规则不变。

台词来源为 `life.js`、`renderer.js`、`pet-feedback.js`、`screenshot.js`、`recording.js`，英文对应 `translations.js`。下表按当前代码整理，改台词时同步更新。

## 显示与边界

- 日常仍按 25–50 分钟随机间隔、至少 4 分钟主动间隔、每天最多 8 次；新增候选台词不增加频率。忙碌、面板、已有气泡与到点提醒仍让主动发言等待。
- 日期、天气、系统占用保持准确的自然说明或数据格式；目前无角色点击入口，不新增天气或信息栏。
- 收藏部分失败仍显示失败数量，不以“收好了”掩盖错误；截图/录屏只在保存成功后说成功台词。
- `{name}` 使用设置里的角色名字；`{days}`、`{minutes}`、`{hours}`、`{count}` 由现有本地逻辑计算。英文保留同样占位符。
- 去掉旧的“冲呀”“真棒”“等你好久”与括号舞台说明；微笑、耳尾和静默陪伴仍按原规则播放。
