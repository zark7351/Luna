# 露娜 · Windows 桌面宠物

露娜是一款以本地收藏为主的轻量 2D 桌面宠物，角色为原创成年二次元女性。当前支持稳定眨眼、单眼眨眼、睁眼笑、害羞脸红与开心表情、气泡反馈、拖放收藏、休息、拖动和托盘。支持发型与服装切换，未来计划加入待办、选项互动和养成。

收藏、截图/录屏成功、换装、提醒保存/到点/完成会触发露娜的单眼眨眼、睁眼笑、害羞脸红或开心表情；角色头发、身体与位置保持固定，仅切换局部眼睛和嘴部，不使用整体缩放、平移或按钮回弹。卡片、气泡与面板保留原位置的淡入，静音仍有表情反馈，尊重系统「减少动态效果」偏好。

## 使用

打开仓库同级的 `LunaPet-Windows` 文件夹，双击 `LunaPet.exe`。请保留整个文件夹；便携程序不需要安装 Node.js。这个开发版没有数字签名。

- 点击角色触发表情和简短气泡；按住拖动。普通气泡显示约 4.5 秒后收起，与时间天气条互斥；无消息时显示信息条。下方按钮默认隐藏，鼠标移到露娜身上或按钮区域后出现；角色与按钮之间的短过渡区域保持可点击，离开后稍作延时收起，返回会取消收起。按钮为收藏夹、截图、录屏、提醒、换装和隐藏的图标，悬停可查看含义。电脑连续 5 分钟没有键鼠操作，露娜会自动闭眼休息；恢复操作后约 2 秒内唤醒，点击角色或拖入内容也会立即唤醒。锁屏或系统休眠时同样休息，解锁/恢复后按空闲状态更新；检测系统空闲时长，不记录按键或鼠标内容。右键系统托盘露娜图标，选择「使用说明」打开简短功能说明，右上角关闭或按 Esc 返回；底部不再常驻文字说明。
- 角色上方的淡紫色窄条用单个小图标表示时段：清晨/傍晚为太阳加地平线，白天为太阳，夜间为月亮；旁边显示 Mon / Tue 等英文星期简称，不显示日期或数字时钟。按电脑本地时间划分清晨（5—8 点）、白天（8—17 点）、傍晚（17—20 点）、夜间（其他时间），属于时段示意，不代表当地实际日出日落。天气使用轻量动画图标。点击尚未设置的天气区域，或进入「设置」，可用「自动定位」通过公网 IP 估算城市，也可手动搜索后选择城市；点击「保存设置」后开始查询。代理可能让定位落在代理所在城市，需手动修正。不会读取精确 GPS 或持续跟踪位置，自动定位仅点击时调用；换城市或换网络后可重新定位。
- 天气每 30 分钟匿名查询 Open-Meteo，点击天气区域可检查刷新，避免重复请求；需要网络，无 API Key。离线时显示已缓存的天气并标记「旧数据」，没有缓存时显示「暂不可用」。来源链接（Open-Meteo / GeoNames / ipwho.is）收在使用说明的「天气来源」折叠项。设置页采用图标操作，准星为自动定位，放大镜为城市搜索，叉号清除城市，勾号保存；清除城市并保存可关闭后续天气查询。时间与星期始终本地显示。
- 将本机图片、视频或其他文件拖到角色上，只保存原文件路径，不再复制文件；拖入文字或链接则保存文字或网址。没有磁盘路径但带实际内容的临时文件也可保存，暂限单文件 64 MB；更大的临时文件请先保存到电脑再拖入。网址保存为链接卡片，仅为预览获取网页元信息及小尺寸封面，不自动下载网页图片/视频原文件。
- 角色下方「收藏」在露娜底部展开小收藏面板，点击四角放大图标打开大收藏夹（保留当前分类和搜索），大界面采用无标题栏的内容网格，顶部空白处可拖动窗口，方框可最大化/还原，叉号关闭；复制/定位/删除操作在悬停或键盘聚焦卡片时出现。按「图片与视频 / 文件 / 文字 / 链接」页签显示多列网格，可搜索、打开、复制和删除。普通文件卡片显示文件名，图片/视频卡片仍以预览为主；复制图标复制实际文件，可粘贴到资源管理器等支持文件粘贴的应用；文件夹图标在资源管理器中定位文件。图片显示缩略图，视频显示首帧并可直接播放；全屏按钮可放大视频，Esc 或视频控制栏可退出；无法解码的格式可先用文件夹图标定位，再交给系统程序。快捷栏使用图标，悬停可查看说明；图片点击预览打开，链接显示网页标题、简介与封面，点击卡片用浏览器打开；首次预览会联网访问对应网站和封面地址，匿名获取，不使用登录 Cookie，也不执行网页脚本。结果缓存到收藏索引，之后可离线查看；失败时可点击重新获取图标重试。收藏夹还有「添加文件」及「收藏剪贴板」入口；剪贴板优先读取 Windows 文件列表（包括复制的视频），本地文件仅引用原路径；直接复制的图片/视频数据保存副本，暂限 64 MB。聊天或网页软件如果只复制了文字/链接而未提供文件或媒体数据，只能收藏其文字/链接；单次最多 10 个文件；本地文件仅引用路径，没有原先复制模式的 1 GB 限制。
- 点击角色下方或收藏夹工具栏的框选图标，或按 **Ctrl + Alt + A** 截图。拖动框选屏幕区域，松开鼠标后自动保存 PNG 到「图片与视频」，可直接预览、复制和定位；Esc 或右键取消，误点不保存。截图期间暂时隐藏露娜和收藏夹，结束后恢复。支持在任一显示器内框选，暂不跨屏拼接；按返回屏幕图像尺寸处理 DPI 缩放。截图文件默认保存到 collection-files，也可在设置中更改新文件保存位置；未框选的屏幕图像只在内存中暂存，不上传、不写入收藏。可在设置中关闭「快捷键截图」，点击勾号保存后立即释放 Ctrl+Alt+A，重启后保持；截图图标和托盘入口仍可使用。快捷键若被其他软件占用，悬停截图按钮可见提示，仍能点击图标或通过托盘截图。
- 点击小圆点图标或托盘「区域录屏」，点击圆点按钮后拖动选择范围，松开开始录制 **MP4**。点击方块停止，或关闭底部录屏面板，会先保存视频并自动加入「图片与视频」；录屏在露娜底部上滑展开，不再弹出独立控制窗口；面板只显示经过时间与录制/停止按钮；录制区域以中心透明、四边闭合的细线框持续标记，鼠标可穿透操作，边框不录入视频。帧率在设置中选择 15 / 24 / 30 / 60 FPS，新配置默认 60 FPS，已有选择保留。本版只录画面、不录麦克风或系统声音，暂不跨屏拼接；帧率是采集目标，实际流畅度取决于电脑负载。录制时露娜及其控制面板保留并排除在录制画面外，大收藏夹暂时隐藏，停止后恢复；锁屏、休眠或屏幕尺寸改变会停止并保存，到点提醒等待录制结束。录屏分块落盘，不受临时拖入文件的 64 MB 限制；没有新增联网、转码依赖或编辑功能。极大区域会按比例限制到约 4K/800 万像素，输出宽高为偶数。
- 点击铃铛或托盘「提醒」，在露娜底部上滑展开小提醒面板，时钟图标为定时，填写本地时间；沙漏图标为倒计时，填写时、分、秒，点击勾号保存。倒计时支持 1 秒至 7 天，提供 5/15/30 分钟与 1 小时快捷选择，卡片显示剩余时间；重启或休眠不暂停倒计时，编辑后保存会按填写的时长重新开始。到点播放轻柔提示音、显示持续气泡并展开小提醒面板（自动出现时不会抢键盘焦点，点击输入框后可正常填写）；气泡点击即完成当前一条，多条按时间先后逐条显示。未完成时每 15 秒响一次，受总声音开关控制，锁屏/休眠/截图/录屏期间暂停，恢复后继续；完成、删除或延后会停止当前提示。提醒列表可滚动，多条事项可完成、延后 5 分钟、编辑或删除，铃铛/勾号页签分别显示待提醒/已完成。叉号或 Esc 收起面板，关闭不删除记录，也保留未保存的输入。露娜运行时每秒检查；休眠/锁屏错过的时间会在恢复后补提示，应用退出时不运行，重启后补提示未触发的过期提醒。截图过程中到点，小面板等待截图结束。提醒保存在本机 reminders.json，不联网、不唤醒休眠电脑、不自动开机。
- 右键系统托盘露娜图标，选择「设置」可修改名字、称呼和窗口置顶；「声音」为全局开关，默认开启，关闭后所有窗口静音（包括视频播放），点击勾号保存后重启保持，按钮、面板开关、页签、搭配选择、收藏、复制、删除、截图开始/完成/取消及提醒操作使用自然的鼠标轻点、轻扣/翻页和金属轻扣等短音效，素材来源与 CC0 许可记录在 ASSET-AUDIO-CREDITS.md，全部本地播放，无角色声音；设置中的「保存位置」可通过文件夹图标选择新截图、录屏及临时收藏的目录，回转箭头恢复默认，点击勾号保存生效；已有文件保留原路径，不自动迁移，录屏期间需先停止再修改保存目录；向下箭头隐藏到托盘，双击系统托盘图标可重新显示。
- 收藏夹工具栏的文件加号为添加文件，剪贴板为收藏文件、图片、文字或链接，也可在收藏夹按 Ctrl+V（搜索框内仍为正常输入粘贴），环形箭头为刷新；分类页签使用图片、文件夹、文字和链接图标加数量，悬停查看分类名，仍支持方向键切换。卡片保留必要的文件名/文字/网页信息；日常界面精简说明，异常仍显示简短反馈。
- 点击露娜下方的衣架图标，从底部上滑展开换装面板，与收藏、录屏、提醒面板保持相同底部位置。发型与服装分为发型头像/衣服图标页签，点击切换；支持方向键/Home/End，卡片区域超出时可滚动。各页用纯图片卡片网格展示，卡片只显示独立发型/服装素材，不显示文字或角色穿着截图；悬停可见名称，点击选择并高亮，上方预览整体搭配。发型可选银紫长卷发/黑长直齐刘海，服装可选紫色长裙/JK 制服配白色膝下袜，两项可分别搭配；预览后点击勾号保存，关闭不保存。切换不影响名字、收藏和提醒，重启后记住选择。原版发型加长裙使用原始素材，其他三种组合使用新的透明三表情图集；当前是预制搭配，不支持导入或任意分层素材。
- 旧版本保存的聊天记录、AI 服务设置和 API Key 会在首次启动新版时从应用状态中移除。请先自行备份任何想留的旧记录。

设置和宠物位置保存在 Windows 当前用户的应用数据目录 `luna-desktop-pet/state.json`；收藏索引仍保存在同一应用数据目录下的 `collection.json`，文件副本默认存入 `collection-files`，新文件可改存到设置选择的目录；每个副本记录自己的保存位置。新收藏的本地文件只记录路径，移动、改名、删除原文件或拔出所在磁盘后会无法预览/打开；临时文件及旧收藏仍保存副本。删除收藏仅移除记录及露娜的副本，绝不删除引用的原文件。收藏只在本机，换电脑或重装系统前需备份该应用数据目录，同时备份自定义保存目录及被引用的原文件；复制索引不会同步原文件或自动修正路径。本版没有打字聊天、自由对话、独立待办列表、循环日程提醒、语音或养成数值。

## 开发与打包

天气城市的名称、坐标及来源保存在个人设置中，天气缓存保存在同一应用数据目录的 `weather.json`，不保存公网 IP 或定位响应原文；均不随源码 Git 同步。

在 Windows 上使用 Node.js 22.12+ 和 npm：

```powershell
npm ci
node node_modules/electron/install.js
npm start
```

运行测试：`npm test`。桌面集成检查：`node_modules/electron/dist/electron.exe . --smoke-test`，使用独立临时用户目录。构建便携版：`node build-portable.cjs`，输出到仓库同级的 `LunaPet-Windows`。打包前关闭正在运行的该便携版，避免文件锁。PowerShell 执行策略拦截 `.ps1` 时，直接使用 Node.js 构建入口。集成检查可验证模拟拖放，资源管理器和浏览器的真实拖放仍需人工验收。

长期开发请阅读 [跨电脑开发指南](CROSS-COMPUTER.md)、[交接记录](HANDOFF.md)、[路线图](ROADMAP.md) 和 [开发规则](AGENTS.md)。源码使用 Electron、普通 JavaScript、HTML 和 CSS。角色素材 `assets/character.png` 为透明三帧精灵图，生成说明见 [ASSET-PROMPT.txt](ASSET-PROMPT.txt)。
