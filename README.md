# 露娜 1.0 · Windows 桌面宠物

露娜是一款以本地收藏为主的轻量 2D 桌面宠物，角色为原创成年二次元女性。当前支持稳定眨眼、单眼眨眼、睁眼笑、害羞脸红与开心表情、气泡反馈、拖放收藏、休息、拖动和托盘。支持发型与服装切换，未来计划加入待办、选项互动和养成。

收藏、截图/录屏成功、换装、提醒保存/到点/完成会触发露娜的单眼眨眼、睁眼笑、害羞脸红或开心表情；角色头发、身体与位置保持固定，仅切换局部眼睛和嘴部，不使用整体缩放、平移或按钮回弹。卡片、气泡与面板保留原位置的淡入，静音仍有表情反馈，尊重系统「减少动态效果」偏好。

程序版本为 1.0.0。当前安装包与便携版包含多语言、原像素高质量录屏、可调整录屏选框、生气互动、关闭到托盘及纯净模式。

支持简体中文与 English：进入「设置」，在顶部「语言」中选择并点击勾号保存，界面和托盘立即切换，重启保持。已有用户默认继续使用中文；名字、昵称、收藏正文和提醒内容保持原文。翻译表全部随程序打包，不联网下载；安装向导仍为中文。

小收藏面板的视频使用紧凑播放/进度控件，「更多」提供倍速、静音、全屏及打开大收藏夹，菜单保持在面板内。新录屏直接采集框选区域的原始像素，绕过浏览器 Canvas 编码；优先使用 NVIDIA NVENC H.264、VBR/CQ 18 和高质量预设，不支持 NVENC 时使用 x264 CRF 16 软件编码。帧率仍可在设置中选择，默认 60 FPS；质量模式按画面内容分配码率，文件可能比旧版更大。不再因超出 4K/800 万像素而缩小画面；已录制的旧文件不会重新编码。

## 使用

推荐运行仓库同级 `LunaPet-Release` 中的 `LunaPet-1.0.0-Setup.exe`，按中文向导选择安装位置；默认安装到当前用户的 `AppData/Local/Programs/LunaPet`，无需管理员权限，可创建桌面及开始菜单快捷方式。安装、重复安装和卸载均保留应用数据与自定义文件保存目录；卸载入口位于 Windows 的「已安装的应用」。安装包已包含运行环境，使用时不需要 Node.js 或联网下载组件。当前安装包没有数字签名。

也可以打开仓库同级的 `LunaPet-Windows` 文件夹，双击 `LunaPet.exe`。便携版请保留整个文件夹。安装版和便携版沿用相同的当前用户数据目录；建议使用其中一个版本，避免同时运行。程序及快捷方式使用露娜头像，系统托盘使用紫色圆环。

- 点击露娜的脑袋、胸部、手臂、腿或脚，触发设置中的对应快捷功能与表情；按住拖动，移动超过 5 DIP 后不会触发点击功能。普通气泡显示约 4.10 秒后收起，点击直接关闭；没有消息时头顶保持空白。下方按钮默认隐藏，鼠标移到露娜身上或按钮区域后出现；角色与按钮之间的短过渡区域保持可点击，离开后稍作延时收起，返回会取消收起。整条功能栏包含收藏夹、截图、录屏、提醒、换装、设置和隐藏到托盘七个图标，两端按内容宽度收窄，悬停可查看含义。电脑连续 5 分钟没有键鼠操作，露娜会自动闭眼休息；恢复操作后约 2 秒内唤醒，点击角色或拖入内容也会立即唤醒。锁屏或系统休眠时同样休息，解锁/恢复后按空闲状态更新；检测系统空闲时长，不记录按键或鼠标内容。右键系统托盘露娜图标，选择「使用说明」打开简短功能说明，右上角关闭或按 Esc 返回；底部不再常驻文字说明。
- 上方常驻信息条已移除。设置里的「身体快捷功能」先选部位，再从九张图标卡片选择收藏、截图、录屏、提醒、换装、日期时间、系统占用、天气或设置，六个部位可以独立配置，也可选相同功能；再次点击当前已选功能卡片会取消选择，全部卡片不选时，该部位通常只触发表情、不打开功能；生气反馈仍会显示气泡，保存与重启后保持。角色悬停时，空配置部位不显示提示，有配置时只显示操作文字（如「点击打开收藏」），不显示部位名称。禁区指每套装扮单独定位、衣物覆盖的胯部中央小椭圆，默认空配置；它与胸部共用敏感点击计数，也可在设置里绑定或取消快捷功能。默认脑袋显示日期时间/星期，胸部显示天气，手臂打开收藏，腿显示系统占用，脚打开换装；勾号保存，重启保持。部位判定跟随 16 套装扮的原图中心并排除透明像素。脑袋为开心、胸部为害羞、手臂为单眼眨眼、腿为微笑、脚为嘟嘴；胸部和禁区在 10 秒内合计点击达到三次后，第三次必定生气并暂停该次快捷操作，未触发时继续害羞并执行快捷功能。一阶段是委屈害羞的原画表情、小嘟嘴和轻微脸红，保持 3 秒且不可打断，无论有无功能配置都会说话。触发后 10 秒内再点胸部或禁区合计三次，会在普通生气播完后升级为睁眼、闭嘴鼓气并带小生气符号的表情，脸红保持一阶段的淡色，说「你个变态！不理你了！」，3 秒后消失 10 秒，期间操作暂停（退出仍可用），回来时说「嘿嘿，我回来啦～」并恢复。表情仅更换眼睛/眉毛/嘴部与脸红，身体原姿势保持。
- 日期气泡用自然对话介绍本机年月日、星期和当前时段，例如“今天是2026年10月8日，星期四。现在是上午10点01分哦。”，整点说“点整”，不播报秒；系统气泡动态显示 CPU、内存和 GPU 百分比，约每秒刷新，严格 5 秒后关闭，点击气泡可提前关闭。首次采样先显示「正在读取系统信息…」及「读取中」，CPU 约 1 秒后得到差值、GPU 等待采样进程首轮结果；真正失败或缺失才显示「暂不可用」，不伪装为 0%。系统采样按需启动，查询停止后释放采样器和 GPU 辅助进程；不保存、不上传。天气气泡按点击查询设置的城市，30 分钟缓存，离线显示上次天气并标注；未设城市时提示先在设置选择。天气城市可搜索或手动点击 IP 城市定位，无 GPS、不保存公网 IP、不持续跟踪。到点提醒优先，普通信息及迟到的查询结果不会覆盖提醒。
- 按下方白条的可见左右边缘判定拖动限制和贴边；拖动露娜到当前显示器工作区的左右边缘后松手，会收起为一个向内箭头按钮；点击展开，仍停在边缘时约 5 秒后再次收起，拖离边缘解除。打开功能面板时临时移回屏幕内，关闭后恢复白条贴边位置；打开功能面板或有未完成提醒时保持展开，提醒到点会自动展开；截图、录屏和视频全屏期间不自动收起。任务栏预览关闭或 Alt+F4 隐藏到托盘；重启恢复完整宠物位置。
- 将本机图片、视频或其他文件拖到角色上，只保存原文件路径，不再复制文件；拖入文字或链接则保存文字或网址。没有磁盘路径但带实际内容的临时文件也可保存，暂限单文件 64 MB；更大的临时文件请先保存到电脑再拖入。网址保存为链接卡片，仅为预览获取网页元信息及小尺寸封面，不自动下载网页图片/视频原文件。
- 角色下方「收藏」在露娜底部展开小收藏面板，点击四角放大图标打开大收藏夹（保留当前分类和搜索），大界面采用无标题栏的内容网格，顶部空白处可拖动窗口，方框可最大化/还原，叉号关闭；复制/定位/删除操作在悬停或键盘聚焦卡片时出现。按「图片与视频 / 文件 / 文字 / 链接」页签显示多列网格，可搜索、打开、复制和删除。普通文件卡片显示文件名，图片/视频卡片仍以预览为主；复制图标复制实际文件，可粘贴到资源管理器等支持文件粘贴的应用；文件夹图标在资源管理器中定位文件。图片显示缩略图，视频显示首帧并可直接播放；全屏按钮可放大视频，Esc 或视频控制栏可退出；无法解码的格式可先用文件夹图标定位，再交给系统程序。快捷栏使用图标，悬停可查看说明；图片点击预览打开，链接显示网页标题、简介与封面，点击卡片用浏览器打开；首次预览会联网访问对应网站和封面地址，匿名获取，不使用登录 Cookie，也不执行网页脚本。结果缓存到收藏索引，之后可离线查看；失败时可点击重新获取图标重试。收藏夹还有「添加文件」及「收藏剪贴板」入口；剪贴板优先读取 Windows 文件列表（包括复制的视频），本地文件仅引用原路径；直接复制的图片/视频数据保存副本，暂限 64 MB。聊天或网页软件如果只复制了文字/链接而未提供文件或媒体数据，只能收藏其文字/链接；单次最多 10 个文件；本地文件仅引用路径，没有原先复制模式的 1 GB 限制。
- 点击角色下方或收藏夹工具栏的框选图标，或按 **Ctrl + Alt + A** 截图。拖动框选屏幕区域，松开鼠标后自动保存 PNG 到「图片与视频」，可直接预览、复制和定位；Esc 或右键取消，误点不保存。截图期间暂时隐藏露娜和收藏夹，结束后恢复。支持在任一显示器内框选，暂不跨屏拼接；按返回屏幕图像尺寸处理 DPI 缩放。截图文件默认保存到 collection-files，也可在设置中更改新文件保存位置；未框选的屏幕图像只在内存中暂存，不上传、不写入收藏。可在设置中关闭「快捷键截图」，点击勾号保存后立即释放 Ctrl+Alt+A，重启后保持；截图图标和托盘入口仍可使用。快捷键若被其他软件占用，悬停截图按钮可见提示，仍能点击图标或通过托盘截图。
- 点击摄像机图标或托盘「区域录屏」，点击圆点按钮后，在真实桌面上的透明选框中拖动选择范围，松开后进入调整状态，不立即录制：拖动四条边或四个角缩放，拖边框控制栏中的尺寸文字移动范围，再点击控制栏圆点开始录制 **MP4**；未开始时点叉号或按 Esc 取消，不生成文件；录屏框选不使用屏幕缩略图替代桌面，文字保持原显示。点击边框控制栏或底部面板的方块停止，或关闭底部录屏面板，会先保存视频并自动加入「图片与视频」；录屏在露娜底部上滑展开，不再弹出独立控制窗口；面板只显示经过时间与录制/停止按钮；录制区域以中心透明、四边闭合的 3 DIP 边框持续标记；控制栏优先放在框外上方，靠近屏幕顶部时移到内侧并限制在屏幕内。录制后锁定范围，桌面中心区域鼠标穿透，控制栏可点击；边框、控制栏均排除在视频外。帧率在设置中选择 15 / 24 / 30 / 60 FPS，新配置默认 60 FPS，已有选择保留。本版只录画面、不录麦克风或系统声音，暂不跨屏拼接；帧率是采集目标，实际流畅度取决于电脑负载。录制时露娜及其控制面板保留并排除在录制画面外，大收藏夹暂时隐藏，停止后恢复；锁屏、休眠或屏幕尺寸改变会停止并保存，到点提醒等待录制结束。录屏分块落盘，不受临时拖入文件的 64 MB 限制；编码组件随包提供，没有新增运行时联网或编辑功能。选中区域按屏幕原始像素保存，不设自动缩小上限；MP4 仍进行有损编码，输出宽高对齐偶数，边缘不足两像素会裁去，不缩放其余画面。编码器不支持所选尺寸时会报告失败，不自动降低分辨率。
- 点击铃铛或托盘「提醒」，在露娜底部上滑展开小提醒面板，时钟图标为定时，填写本地时间；沙漏图标为倒计时，填写时、分、秒，点击勾号保存。倒计时支持 1 秒至 7 天，提供 5/15/30 分钟与 1 小时快捷选择，卡片显示剩余时间；重启或休眠不暂停倒计时，编辑后保存会按填写的时长重新开始。到点播放轻柔提示音并显示持续气泡，自动出现时不展开面板、不抢键盘焦点。气泡内部右侧勾号直接完成当前一条，不打开提醒面板；点击气泡消息区域才展开提醒面板，点击输入框可正常填写。多条到点提醒按时间先后在气泡中逐条显示，完成一条后继续下一条。未完成时每 15 秒响一次，受总声音开关控制，锁屏/休眠/截图/录屏期间暂停，恢复后继续；完成、删除或延后会停止当前提示。提醒列表可滚动，多条事项可完成、延后 5 分钟、编辑或删除，铃铛/勾号页签分别显示待提醒/已完成。叉号或 Esc 收起面板，关闭不删除记录，也保留未保存的输入。露娜运行时每秒检查；休眠/锁屏错过的时间会在恢复后补提示，应用退出时不运行，重启后补提示未触发的过期提醒。截图过程中到点，小面板等待截图结束。提醒保存在本机 reminders.json，不联网、不唤醒休眠电脑、不自动开机。
- 右键系统托盘露娜图标，选择「设置」可修改名字、称呼和窗口置顶；「声音」为全局开关，默认开启，关闭后所有窗口静音（包括视频播放），点击勾号保存后重启保持，按钮、面板开关、页签、搭配选择、收藏、复制、删除、截图开始/完成/取消及提醒操作使用自然的鼠标轻点、轻扣/翻页和金属轻扣等短音效，素材来源与 CC0 许可记录在 ASSET-AUDIO-CREDITS.md，全部本地播放，无角色声音；设置中的「保存位置」可通过文件夹图标选择新截图、录屏及临时收藏的目录，回转箭头恢复默认，点击勾号保存生效；已有文件保留原路径，不自动迁移，录屏期间需先停止再修改保存目录；向下箭头隐藏到托盘，双击系统托盘图标可重新显示。
- 收藏夹工具栏的文件加号为添加文件，剪贴板为收藏文件、图片、文字或链接，也可在收藏夹按 Ctrl+V（搜索框内仍为正常输入粘贴），环形箭头为刷新；分类页签使用图片、文件夹、文字和链接图标加数量，悬停查看分类名，仍支持方向键切换。卡片保留必要的文件名/文字/网页信息；日常界面精简说明，异常仍显示简短反馈。
- 点击露娜下方的衣架图标，从底部上滑展开换装面板，与收藏、录屏、提醒面板保持相同底部位置。发型与服装分为发型头像/衣服图标页签，点击切换；支持方向键/Home/End，卡片区域超出时可滚动。各页用纯图片卡片网格展示，卡片只显示独立发型或衣服本身，服装卡片不含鞋帽、袜子等配件，不显示文字或角色穿着截图；悬停可见名称，点击选择并高亮，上方预览整体搭配。发型可选银紫长卷发、黑长直齐刘海、银色短发、粉色双马尾，服装可选紫色长裙、JK 制服、秘书制服、护士制服；白袜均到膝下，两项可独立选择，共 16 种搭配；预览后点击勾号保存，关闭不保存。切换不影响名字、收藏和提醒，重启后记住选择。身体、头发与服装采用完整原画，眼睛/嘴部/脸红使用独立引用的表情包；原有四种搭配保留原素材，12 张新增搭配使用透明单帧整身图复用原表情包，各自校准眼嘴位置与尺寸，明显动作另补原画。当前是预制搭配，不支持用户导入或任意服装分层。素材制作规格见 CHARACTER-ASSETS.md。
- 旧版本保存的聊天记录、AI 服务设置和 API Key 会在首次启动新版时从应用状态中移除。请先自行备份任何想留的旧记录。

设置和宠物位置保存在 Windows 当前用户的应用数据目录 `luna-desktop-pet/state.json`；收藏索引仍保存在同一应用数据目录下的 `collection.json`，文件副本默认存入 `collection-files`，新文件可改存到设置选择的目录；每个副本记录自己的保存位置。新收藏的本地文件只记录路径，移动、改名、删除原文件或拔出所在磁盘后会无法预览/打开；临时文件及旧收藏仍保存副本。删除收藏仅移除记录及露娜的副本，绝不删除引用的原文件。收藏只在本机，换电脑或重装系统前需备份该应用数据目录，同时备份自定义保存目录及被引用的原文件；复制索引不会同步原文件或自动修正路径。本版没有打字聊天、自由对话、独立待办列表、循环日程提醒、语音或养成数值。

## 开发与打包

系统信息不需要网络。天气恢复为用户点击时查询；城市搜索与天气使用 [Open-Meteo](https://open-meteo.com/)（数据与 GeoNames 地名按上游署名要求使用），用户点击的 IP 城市定位使用 [ipwho.is](https://ipwhois.io/)。不提供常驻天气条、不自动定位或轮询天气。旧信息条开关在状态迁移时清除，其余个人数据保持。

在 Windows 上使用 Node.js 22.12+ 和 npm：

```powershell
npm ci
node node_modules/electron/install.js
npm start
```

运行测试：`npm test`。桌面集成检查：`node_modules/electron/dist/electron.exe . --smoke-test`，使用独立临时用户目录；加 `--stats-live-test` 可额外验证本机真实 CPU/内存/GPU 采样（不同驱动可能不提供 GPU 计数器）。构建便携版：`node build-portable.cjs`，输出到仓库同级的 `LunaPet-Windows`。打包前关闭正在运行的该便携版，避免文件锁。PowerShell 执行策略拦截 `.ps1` 时，直接使用 Node.js 构建入口。集成检查可验证模拟拖放，资源管理器和浏览器的真实拖放仍需人工验收。

角色素材采用整身原画＋可复用表情的混合方案，新增服装与动作的规范见 [素材指南](CHARACTER-ASSETS.md)。

构建 1.0 安装包：`node build-installer.cjs`（或 `npm run build:installer`），会先构建便携版，再输出到仓库同级 `LunaPet-Release`。首次构建按固定版本下载并校验 rcedit 2.0.0 与 Inno Setup 6.7.3，缓存到不入 Git 的 `.build-tools`；此联网仅发生于开发时，安装与日常运行不依赖这些工具。安装包源文件、工具来源和隔离验证方法见 [安装包指南](installer/README.md)。程序版本统一为 1.0.0；后续更新需同时修改 package.json 与 package-lock.json 的版本。

长期开发请阅读 [跨电脑开发指南](CROSS-COMPUTER.md)、[交接记录](HANDOFF.md)、[路线图](ROADMAP.md) 和 [开发规则](AGENTS.md)。源码使用 Electron、普通 JavaScript、HTML 和 CSS。角色素材 `assets/character.png` 为透明三帧精灵图，生成说明见 [ASSET-PROMPT.txt](ASSET-PROMPT.txt)。

### 本地录屏编码组件

便携版/安装版自带 FFmpeg，不需要另装编码器，也不在运行时下载。开发目录首次启用原生录屏可执行 `node -e "require('./prepare-build-tools.cjs').ensureFFmpeg()"`；打包入口会自动准备并校验该组件。仅缺少组件的源码运行沿用浏览器编码。组件授权说明见 FFMPEG-NOTICE.md；公开分发须提供其完整对应源码。

频繁点击规则：胸部/禁区在10秒内合计3次必定进入一阶段，再额外3次升级；没有随机概率，不需要预览参数。

纯净模式：点击整条功能栏的齿轮进入设置，开启「纯净模式」并勾号保存；角色隐藏，功能条常驻。左侧点状拖动柄可移动功能条，拖到左右屏幕边缘后松手收起为向内箭头；点击恢复小条，仍贴边约 5 秒后再次收起，拖离边缘解除。设置开关重启保持。收藏、录屏、提醒和设置等面板打开时自动展开窗口并暂停收起，关闭后收回小条；普通角色气泡隐藏，待处理提醒继续显示。点击任务栏预览的关闭按钮或按 Alt+F4 只隐藏到托盘，功能条最右侧向下箭头可隐藏到托盘；双击托盘恢复，右键托盘→退出才结束程序。大收藏夹关闭按钮仍只关闭该面板。
