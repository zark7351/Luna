# claude maid 1.0 · Windows 桌面宠物

claude maid 是一款以本地收藏为主的轻量 2D 桌面宠物，当前角色名为克劳德。当前默认形象是 **2D 插画克劳德**：橙色长卷发、虎纹耳朵和尾巴、黑白几何服装，单手托腮、温柔慵懒地看向前方。透明待机动画包含眨眼、耳朵轻抖和缓慢摆尾，8 秒顺序循环。横向半身图保持原比例和四周留白，耳朵、尾巴完整显示。形象基准见 [已确认原图](design/luna-2d/default-pose.png)，导出说明见 [2D 待机动画](design/luna-2d/idle/README.md)。支持气泡反馈、拖放收藏、休息、拖动和托盘。换装已移除。

收藏成功、完成提醒、欢迎回来、轻点脑袋和偶尔的安静陪伴会出现约 2.6 秒的闭口微笑，只有嘴部局部变化，柔和回到原表情，不整体小跳、不打断待机和耳尾动作；到点提醒优先。轻点脑袋通常不说话，陪伴互动开启时偶尔说“嗯？怎么了？”。主动陪伴沿用原有频率与每日上限，部分互动只微笑不出气泡。全部角色台词已按温柔、慵懒、松弛且略带大小姐气质统一润色：少感叹、不催促，不因用户离开而委屈。日常问候、欢迎回来、休息关心、操作反馈及英文版同步；完整 68 项场景文案见源码目录 `docs/CLAUDE-DIALOGUE.md`，自定义名字、称呼和提醒原文保持。

截图/录屏成功、提醒保存/到点和其他身体点击也会让克劳德做出反应：有对应姿势动画时切换过去，播完回到待机；还没有素材的姿势保持待机，不再用全身小跳代替。睡眠时切换为已确认的贴臂睡姿，6 秒轻呼吸循环，脸颊和手臂保持固定。卡片、气泡与面板保留原位置的淡入，静音仍有反馈，尊重系统「减少动态效果」偏好（此时停在第一帧）。界面配色跟随角色，改为橘色、奶白和深棕。

程序版本为 1.0.0。当前安装包与便携版包含多语言、原像素高质量录屏、可调整录屏选框、关闭到托盘及精简模式。

支持简体中文与 English：进入「设置」，在顶部「语言」中选择并点击勾号保存，界面和托盘立即切换，重启保持。已有用户默认继续使用中文；名字、昵称、收藏正文和提醒内容保持原文。翻译表全部随程序打包，不联网下载；安装向导仍为中文。

小收藏面板的视频使用紧凑播放/进度控件，「更多」提供倍速、静音、全屏及打开大收藏夹，菜单保持在面板内。新录屏直接采集框选区域的原始像素，绕过浏览器 Canvas 编码；优先使用 NVIDIA NVENC H.264、VBR/CQ 18 和高质量预设，不支持 NVENC 时使用 x264 CRF 16 软件编码。帧率仍可在设置中选择，默认 60 FPS；质量模式按画面内容分配码率，文件可能比旧版更大。不再因超出 4K/800 万像素而缩小画面；已录制的旧文件不会重新编码。

鼠标放在人物的非透明区域，向上滚轮放大、向下缩小，范围为默认的 **60%–180%**，每档 10%；鼠标停在角色的非透明区域时，按鼠标中键（按下滚轮）恢复默认 100%，并自动保存、重启保留。只缩放人物，面板和按钮保持正常大小，气泡跟随人物高度。

桌宠主窗口不显示任务栏图标或预览，只保留花饰系统托盘；正常模式、精简模式和从托盘恢复后均保持。大收藏夹打开时仍有独立任务栏入口。桌宠获得焦点时按 Alt+F4 会隐藏全部应用窗口，进程和花饰托盘继续运行；双击花饰可恢复。只有托盘或转盘的「退出」才结束程序。已有收藏、提醒和设置沿用原本的数据目录。

## 使用

在人物或精简模式小花上按住右键可直接拖选转盘功能：拖到扇区会高亮，松开右键执行；拖回中心或盘外松开取消，Esc、失焦或鼠标捕获中断也会取消。普通右键轻点后再单击功能的方式保留；长按不移动再松开会收起转盘。右键拖选不会拖动人物或小花，精简模式靠边展开时保持正确的选择位置。

在设置的「快捷键」区可自定义五项全局快捷键：默认截图 **Ctrl + Alt + A**、录屏 **Ctrl + Alt + R**、收藏夹 **Ctrl + Alt + C**；提醒和精简模式默认留空。点击输入框后按组合键，点击 × 清除，或恢复默认，最后点击勾号保存。支持 Ctrl/Alt/Win 组合键或 F1–F24；重复或被占用时提示，保存失败保留原配置。录屏快捷键在空闲时启动框选，调整后仍需点击开始录制，录制时再次按下停止保存；提醒打开面板，精简模式切换开关。旧版关闭截图快捷键的设置继续保留。

精简模式只显示小花。点击后先隐藏小花，以花的屏幕中心展开功能转盘；靠近工作区四边或角落时向内调整，保证转盘完整可见。关闭后恢复原小花位置。拖动限制、左右贴边及上下边界均按 56 DIP 小花计算，不沿用正常模式的透明窗口范围；面板展开时临时移入屏幕，关闭后归位。

便携版和安装包均已按新名称构建，安装包通过隔离安装/卸载与文件一致性检查。执行 `node build-installer.cjs` 后，安装包输出到仓库同级 `claude maid-Release/claude maid-1.0.0-Setup.exe`，按中文向导选择安装位置；默认安装到当前用户的 `AppData/Local/Programs/claude maid`，无需管理员权限，可创建桌面及开始菜单快捷方式。安装、重复安装和卸载均保留应用数据与自定义文件保存目录；卸载入口位于 Windows 的「已安装的应用」。安装包包含运行环境，使用时不需要 Node.js 或联网下载组件，未配置数字签名。

也可以打开仓库同级的 `claude maid-Windows` 文件夹，双击 `claude maid.exe`。便携版请保留整个文件夹。安装版和便携版沿用相同的当前用户数据目录；建议使用其中一个版本，避免同时运行。程序及快捷方式使用新 2D 托腮形象头像，系统托盘使用十四瓣花饰。软件名称统一为 claude maid；当前角色仍称克劳德（小克），后续计划加入 GPT 娘供切换，目前未实现角色切换。

- 点击克劳德画面中可见的脑袋、胸部或手臂，播放对应反应，不打开功能，脑袋偶尔配一句简短反馈；点击左右耳，所点的耳朵快速抖动并回弹，第二下较轻（约半秒）；点击尾巴，尾巴独立向外轻甩，再小幅回摆归位（约 1.3 秒）；上方弯钩保持形状和粗细，头发作为前景保持不动。局部动作不带动整个人物，不弹气泡；同部位动作期间不叠加或重启，不同部位可同时响应；按住拖动，移动超过 5 DIP 后不会触发点击。普通气泡显示约 4.10 秒后收起，点击直接关闭；没有消息时头顶保持空白。右键点击克劳德弹出功能转盘：收藏夹、截图、录屏、提醒、设置、精简模式、陪伴互动、隐藏到托盘、退出九项。扇形按顺时针依次旋入展开，悬停或方向键选中时高亮并略微外凸，中心显示图标和名称（精简模式和陪伴互动会显示开关状态）；按 Esc、点空白处或窗口失去焦点时收起。普通模式不显示下方功能条，两种模式贴边后均显示半朵花，左边露右半朵、右边露左半朵，点击展开；升级后第一次启动会提示一次右键用法。每天按本机时间 **22:00–次日 07:00、12:30–14:00** 到点入睡，在这些时段内启动也会入睡。点击人物任一非透明位置可唤醒（耳朵、尾巴也只唤醒），之后在睡眠时段内闲置满 5 分钟才会再睡；普通鼠标移动或打字不会唤醒。07:00 和 14:00 自动醒来，其余时段不因闲置或锁屏睡觉。到点提醒或拖入收藏也会唤醒，未完成的到点提醒期间保持清醒。锁屏/系统恢复时重新检查时段；只读取本机时间和系统空闲时长，不记录键鼠内容。右键系统托盘克劳德图标，选择「使用说明」打开简短功能说明，右上角关闭或按 Esc 返回；底部不再常驻文字说明。
- 陪伴互动（设置中「陪伴互动」开关，默认开启）：克劳德每天第一次见面会按时段打招呼，周一、周五、周末和认识第 7/30/100 天等纪念日会多说一句；第一次使用时自我介绍。离开后回来，她会按离开时长说不同的话。连续忙碌约 90 分钟会提醒休息（每天最多 3 次），深夜 23:30 后还在用电脑会劝你早睡（每晚最多 2 次）。平时每隔 25–50 分钟偶尔自言自语，或提起今天截了几张图、收藏了几样东西、完成了几个提醒。主动发言之间至少间隔 4 分钟，每天最多 8 句；有气泡、面板、提醒、拖动时，或在精简模式、贴边收起、隐藏到托盘时，她会保持安静。犯困时段（午后、深夜）或连续忙碌后眨眼会变慢，平时偶尔连眨两下。拖动她时偶尔会说话，快速左右甩动会喊头晕。所有判断都在本地完成，只用到系统空闲时长和本机时间；每天的计数与认识日期保存在本地 state.json。关闭开关后恢复原来的固定台词和眨眼。
- 身体部位快捷功能已移除，点击只做动画反馈。默认半身图按实际头部、胸部、两侧手臂、左右耳和尾巴判定，托腮的手优先，透明处不触发；腿、脚与禁区未显示，不设点击区域。脑袋为局部微笑、胸部为害羞、手臂为单眼眨眼，对应姿势尚未制作时保持待机，不整体跳动。连续点击始终保持普通反馈，不再累计次数、触发生气、隐藏角色或锁定操作。
- 日期时间、天气和系统占用气泡目前没有入口（以后打算用动画表现）。读取代码保留在 `shortcut-bubbles.js`（`dateText`、`statsText`、`weatherText` 与按需刷新）和主进程的 `system-stats`、`weather-current` IPC：系统采样按需启动，停止后释放；天气 30 分钟缓存；设置里的天气城市搜索和 IP 定位仍可用。
- 按下方白条的可见左右边缘判定拖动限制和贴边；拖动克劳德到当前显示器工作区的左右边缘后松手，会收起为半朵花按钮；点击展开，仍停在边缘时约 5 秒后再次收起，拖离边缘解除。打开功能面板时临时移回屏幕内，关闭后恢复白条贴边位置；打开功能面板或有未完成提醒时保持展开，提醒到点会自动展开；截图、录屏和视频全屏期间不自动收起。桌宠获得焦点时 Alt+F4 隐藏到托盘；重启恢复完整宠物位置。
- 将本机图片、视频或其他文件拖到角色上，只保存原文件路径，不再复制文件；拖入文字或链接则保存文字或网址。没有磁盘路径但带实际内容的临时文件也可保存，暂限单文件 64 MB；更大的临时文件请先保存到电脑再拖入。网址保存为链接卡片，仅为预览获取网页元信息及小尺寸封面，不自动下载网页图片/视频原文件。
- 角色下方「收藏」在克劳德底部展开小收藏面板，点击四角放大图标打开大收藏夹（保留当前分类和搜索），大界面采用无标题栏的内容网格，顶部空白处可拖动窗口，方框可最大化/还原，叉号关闭；复制/定位/删除操作在悬停或键盘聚焦卡片时出现。按「图片与视频 / 文件 / 文字 / 链接」页签显示多列网格，可搜索、打开、复制和删除。普通文件卡片显示文件名，图片/视频卡片仍以预览为主；复制图标复制实际文件，可粘贴到资源管理器等支持文件粘贴的应用；文件夹图标在资源管理器中定位文件。图片显示缩略图，视频显示首帧并可直接播放；全屏按钮可放大视频，Esc 或视频控制栏可退出；无法解码的格式可先用文件夹图标定位，再交给系统程序。快捷栏使用图标，悬停可查看说明；图片点击预览打开，链接显示网页标题、简介与封面，点击卡片用浏览器打开；首次预览会联网访问对应网站和封面地址，匿名获取，不使用登录 Cookie，也不执行网页脚本。结果缓存到收藏索引，之后可离线查看；失败时可点击重新获取图标重试。收藏夹还有「添加文件」及「收藏剪贴板」入口；剪贴板优先读取 Windows 文件列表（包括复制的视频），本地文件仅引用原路径；直接复制的图片/视频数据保存副本，暂限 64 MB。聊天或网页软件如果只复制了文字/链接而未提供文件或媒体数据，只能收藏其文字/链接；单次最多 10 个文件；本地文件仅引用路径，没有原先复制模式的 1 GB 限制。
- 点击角色下方或收藏夹工具栏的框选图标，或按 **Ctrl + Alt + A** 截图。拖动框选屏幕区域，松开鼠标后自动保存 PNG 到「图片与视频」，可直接预览、复制和定位；Esc 或右键取消，误点不保存。截图期间暂时隐藏克劳德和收藏夹，结束后恢复。支持在任一显示器内框选，暂不跨屏拼接；冻结画面按完整屏幕尺寸显示，包含任务栏，不压缩到工作区；框选按返回屏幕图像尺寸处理 DPI 缩放。截图文件默认保存到 collection-files，也可在设置中更改新文件保存位置；未框选的屏幕图像只在内存中暂存，不上传、不写入收藏。可在设置的「快捷键」区修改或清除截图绑定，点击勾号保存后生效并在重启后保持；截图图标和托盘入口仍可使用。快捷键若被其他软件占用，悬停截图按钮可见提示，仍能点击图标或通过托盘截图。
- 点击摄像机图标或托盘「区域录屏」，点击框选区域按钮后，在真实桌面上的透明选框中拖动选择范围，松开后进入调整状态，不立即录制：拖动四条边或四个角缩放，拖边框控制栏中的尺寸文字移动范围，再点击控制栏圆点开始录制 **MP4**；未开始时点叉号或按 Esc 取消，不生成文件；录屏框选不使用屏幕缩略图替代桌面，文字保持原显示。点击边框控制栏或底部面板的方块停止，或关闭底部录屏面板，会先保存视频并自动加入「图片与视频」；录屏在克劳德底部上滑展开，不再弹出独立控制窗口；面板只显示经过时间与录制/停止按钮；录制区域以中心透明、四边闭合的 3 DIP 边框持续标记；控制栏优先放在框外上方，靠近屏幕顶部时移到内侧并限制在屏幕内。录制后锁定范围，桌面中心区域鼠标穿透，控制栏可点击；边框、控制栏均排除在视频外。帧率在设置中选择 15 / 24 / 30 / 60 FPS，新配置默认 60 FPS，已有选择保留。本版只录画面、不录麦克风或系统声音，暂不跨屏拼接；帧率是采集目标，实际流畅度取决于电脑负载。录制时克劳德及其控制面板保留并排除在录制画面外，大收藏夹暂时隐藏，停止后恢复；锁屏、休眠或屏幕尺寸改变会停止并保存，到点提醒等待录制结束。录屏分块落盘，不受临时拖入文件的 64 MB 限制；编码组件随包提供，没有新增运行时联网或编辑功能。选中区域按屏幕原始像素保存，不设自动缩小上限；MP4 仍进行有损编码，输出宽高对齐偶数，边缘不足两像素会裁去，不缩放其余画面。编码器不支持所选尺寸时会报告失败，不自动降低分辨率。
- 点击铃铛或托盘「提醒」，在克劳德底部上滑展开小提醒面板，时钟图标为定时，填写本地时间；沙漏图标为倒计时，填写时、分、秒，点击勾号保存。倒计时支持 1 秒至 7 天，提供 5/15/30 分钟与 1 小时快捷选择，卡片显示剩余时间；重启或休眠不暂停倒计时，编辑后保存会按填写的时长重新开始。到点播放轻柔提示音并显示持续气泡，自动出现时不展开面板、不抢键盘焦点。气泡内部右侧勾号直接完成当前一条，不打开提醒面板；点击气泡消息区域才展开提醒面板，点击输入框可正常填写。多条到点提醒按时间先后在气泡中逐条显示，完成一条后继续下一条。未完成时每 15 秒响一次，受总声音开关控制，锁屏/休眠/截图/录屏期间暂停，恢复后继续；完成、删除或延后会停止当前提示。提醒列表可滚动，多条事项可完成、延后 5 分钟、编辑或删除，铃铛/勾号页签分别显示待提醒/已完成。叉号或 Esc 收起面板，关闭不删除记录，也保留未保存的输入。克劳德运行时每秒检查；休眠/锁屏错过的时间会在恢复后补提示，应用退出时不运行，重启后补提示未触发的过期提醒。截图过程中到点，小面板等待截图结束。提醒保存在本机 reminders.json，不联网、不唤醒休眠电脑、不自动开机。
- 右键系统托盘克劳德图标，选择「设置」可修改名字、称呼和窗口置顶；「声音」为全局开关，默认开启，关闭后所有窗口静音（包括视频播放），点击勾号保存后重启保持，按钮、面板开关、页签、搭配选择、收藏、复制、删除、截图开始/完成/取消及提醒操作使用自然的鼠标轻点、轻扣/翻页和金属轻扣等短音效，素材来源与 CC0 许可记录在 ASSET-AUDIO-CREDITS.md，全部本地播放，无角色声音；设置中的「保存位置」可通过文件夹图标选择新截图、录屏及临时收藏的目录，回转箭头恢复默认，点击勾号保存生效；已有文件保留原路径，不自动迁移，录屏期间需先停止再修改保存目录；向下箭头隐藏到托盘，双击系统托盘图标可重新显示。
- 收藏夹工具栏的文件加号为添加文件，剪贴板为收藏文件、图片、文字或链接，也可在收藏夹按 Ctrl+V（搜索框内仍为正常输入粘贴），环形箭头为刷新；分类页签使用图片、文件夹、文字和链接图标加数量，悬停查看分类名，仍支持方向键切换。卡片保留必要的文件名/文字/网页信息；日常界面精简说明，异常仍显示简短反馈。
- 收藏夹默认打开「全部」页签：置顶的内容在最上面，其余按「今天 / 昨天 / 更早」分组、最新在前；图片与视频、文件、文字、链接四个页签用于筛选。搜索框总是在全部内容里搜。卡片右上角可置顶或取消置顶。同一段文字、同一个链接或同一个本地文件再次收藏时，不会重复新增，而是把原来那条移到最前面。拖进来的本地文件只记录原文件位置，卡片左下角标「引用」，可点「保存副本」复制一份到克劳德的保存目录，之后原文件移动或删除都不受影响；原文件已不在时标「已失效」。工具栏的笔形图标可以直接写便签，Ctrl+Enter 保存、Esc 取消。「全部」页底部会在有 30 天前且未置顶的收藏时出现「清理」按钮，确认后删除这些条目及克劳德保存的副本，拖进来的原文件不受影响。
- 旧版本保存的聊天记录、AI 服务设置和 API Key 会在首次启动新版时从应用状态中移除。请先自行备份任何想留的旧记录。

设置和宠物位置保存在 Windows 当前用户的应用数据目录 `LunaPet/state.json`；收藏索引仍保存在同一应用数据目录下的 `collection.json`，文件副本默认存入 `collection-files`，新文件可改存到设置选择的目录；每个副本记录自己的保存位置。新收藏的本地文件只记录路径，移动、改名、删除原文件或拔出所在磁盘后会无法预览/打开；临时文件及旧收藏仍保存副本。删除收藏仅移除记录及克劳德的副本，绝不删除引用的原文件。收藏只在本机，换电脑或重装系统前需备份该应用数据目录，同时备份自定义保存目录及被引用的原文件；复制索引不会同步原文件或自动修正路径。本版没有打字聊天、自由对话、独立待办列表、循环日程提醒、语音或养成数值。

## 开发与打包

系统信息不需要网络。天气只在被请求时查询；城市搜索与天气使用 [Open-Meteo](https://open-meteo.com/)（数据与 GeoNames 地名按上游署名要求使用），用户点击的 IP 城市定位使用 [ipwho.is](https://ipwhois.io/)。不提供常驻天气条、不自动定位或轮询天气。旧信息条开关在状态迁移时清除，其余个人数据保持。

在 Windows 上使用 Node.js 22.12+ 和 npm：

```powershell
npm ci
node node_modules/electron/install.js
npm start
```

运行测试：`npm test`。桌面集成检查：`node_modules/electron/dist/electron.exe . --smoke-test`，使用独立临时用户目录；加 `--stats-live-test` 可额外验证本机真实 CPU/内存/GPU 采样（不同驱动可能不提供 GPU 计数器）。构建便携版：`node build-portable.cjs`，输出到仓库同级的 `claude maid-Windows`。打包前关闭正在运行的该便携版，避免文件锁。PowerShell 执行策略拦截 `.ps1` 时，直接使用 Node.js 构建入口。集成检查可验证模拟拖放，资源管理器和浏览器的真实拖放仍需人工验收。

角色素材是按姿势划分的 WebP 帧图集，新增姿势的素材要求见 [素材指南](CHARACTER-ASSETS.md)。

构建 1.0 安装包：`node build-installer.cjs`（或 `npm run build:installer`），会先构建便携版，再输出到仓库同级 `claude maid-Release`。首次构建按固定版本下载并校验 rcedit 2.0.0 与 Inno Setup 6.7.3，缓存到不入 Git 的 `.build-tools`；此联网仅发生于开发时，安装与日常运行不依赖这些工具。安装包源文件、工具来源和隔离验证方法见 [安装包指南](installer/README.md)。程序版本统一为 1.0.0；后续更新需同时修改 package.json 与 package-lock.json 的版本。

长期开发请阅读 [跨电脑开发指南](CROSS-COMPUTER.md)、[交接记录](HANDOFF.md)、[路线图](ROADMAP.md) 和 [开发规则](AGENTS.md)。源码使用 Electron、普通 JavaScript、HTML 和 CSS。角色待机动画在 `assets/luna-2d/idle.webp`，由 `design/chibi/build-atlas.py` 从透明序列帧打包。

### 本地录屏编码组件

便携版/安装版自带 FFmpeg，不需要另装编码器，也不在运行时下载。开发目录首次启用原生录屏可执行 `node -e "require('./prepare-build-tools.cjs').ensureFFmpeg()"`；打包入口会自动准备并校验该组件。仅缺少组件的源码运行沿用浏览器编码。组件授权说明见 FFMPEG-NOTICE.md；公开分发须提供其完整对应源码。

连续点击不会触发生气、隐藏角色或锁定功能；每次点击只播放对应的普通反应。

精简模式：在功能转盘或设置里开启「精简模式」；角色和功能条都隐藏，只留下她头上那朵小花。点击小花（或右键）在上方打开功能转盘，按住小花可拖动位置，拖到左右屏幕边缘后松手收起为向内箭头；点击恢复小花，仍贴边约 5 秒后再次收起，拖离边缘解除。再次在转盘里点「精简模式」即可退出，设置开关重启保持。转盘和收藏、录屏、提醒、设置等面板打开时自动展开窗口并暂停收起，关闭后收回；普通角色气泡隐藏，待处理提醒继续显示。点击任务栏预览的关闭按钮或按 Alt+F4 只隐藏到托盘；双击托盘恢复，右键托盘→退出才结束程序。大收藏夹关闭按钮仍只关闭该面板。
